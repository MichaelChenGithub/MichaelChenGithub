## About

Michael Chen is a data engineer with more than two years of production experience building large-scale data infrastructure across e-commerce and analytics domains. His technical breadth spans the modern data stack, including Spark, Kafka, Apache Iceberg, Airflow, dbt, BigQuery, and Snowflake.

At Merkle, he engineered a cross-cloud ETL pipeline processing roughly 100 million Google Analytics events to support L'Oreal's recommendation system retraining, while designing a Kimball star schema over terabyte-scale data that reduced query latency by 90%. These were production systems with measurable business impact, delivered in close collaboration with ML engineers and data scientists.

He is currently completing his Master's in Computer Science at Virginia Tech and is targeting roles that value strong ETL design, dimensional modeling, and big data fluency.
